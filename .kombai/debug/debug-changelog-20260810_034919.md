## Changes Made

### 1. Made hero frame loading concurrent
- **File:** `src/app/components/HeroScrollBackground.jsx`
- **Change:** Replaced the sequential frame-loading loop with `Promise.all`, allowing all 36 hero frames to load concurrently instead of blocking scroll animation behind one request at a time.
- **Why:** The attached DOM data showed a very slow initial load, and the hero did not have enough loaded frames available while the user was scrolling.
- **Revert:** Restore the original `loadImages` loop that awaits `loadFrame(i)` for each frame.

### 2. Render the current scroll frame as frames become available
- **File:** `src/app/components/HeroScrollBackground.jsx`
- **Change:** Stored images in `imagesRef`, rendered the frame matching the current `scrollYProgress` after each successful image load, and kept a ref to the latest render function.
- **Why:** Scroll-driven rendering previously waited for every image to finish before `loaded` became true, so early scrolling could appear unresponsive.
- **Revert:** Remove `imagesRef`, `lastRenderedFrameRef`, `renderFrameRef`, and restore the prior state-driven image rendering.

### 3. Prevent redundant frame work and handle failed loads
- **File:** `src/app/components/HeroScrollBackground.jsx`
- **Change:** Skip rendering the same frame repeatedly, update load progress for failed frames, and use the ref-backed image collection for resize rendering.
- **Why:** Keeps scroll updates lightweight and prevents one failed frame from leaving loading state incomplete.
- **Revert:** Restore the previous `loaded`/`images` guards and frame callback implementation.

## Verification

- The attached DOM selection was `nextjs-portal`, an invisible Next.js dev portal, not the page scroll container.
- Browser reproduction confirmed page scroll position changes and the canvas center pixel changes after scrolling.
- No application console errors were reported during reproduction.
- Vercel Analytics and Speed Insights requests remain blocked in the local environment; these are unrelated to the hero scroll behavior.
